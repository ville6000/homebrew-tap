# ville6000/homebrew-tap

Homebrew casks for my command line tools. They work on macOS and Linux.

| Tool | Install |
| --- | --- |
| [toggl-cli](https://github.com/ville6000/toggl-cli): command line client for Toggl Track | `brew install ville6000/tap/toggl-cli` |
| [7pace-cli](https://github.com/ville6000/7pace-cli): post worklogs to 7pace Timetracker, also in bulk from toggl-cli | `brew install ville6000/tap/7pace-cli` |

Each tool's release workflow generates its cask with
[GoReleaser](https://goreleaser.com/), so don't edit `Casks/*.rb` by hand.
